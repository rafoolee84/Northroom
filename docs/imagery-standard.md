# Northroom imagery standard

1. **Hero:** clear full-product manufacturer photo (item fully visible).
2. **Gallery:** 1 lifestyle (optional) + **3–5 angles, same crop / product**.
3. No Unsplash/Pexels lifestyle stock, no model-only shots that hide the SKU, no plant/prop crops as the only hero.
4. Prefer supplier CDN URLs that HTTP 200; never invent Shopify paths.
5. Demoted SKUs stay shoppable in category but off Featured until photos clear.
